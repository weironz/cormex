# Cormex 应用

Cormex 记忆服务的界面：**登录 + 记忆浏览**。桌面与 Web 一套代码。

它只做四件事，而这四件事恰好是这个产品与 mem0 / zep / Letta 的差异所在：

- **检索** —— 四路召回（BM25 / 向量 / 图 / 时近）RRF 融合后的结果，
  每条事实标出它是被**哪几路**捞出来的，而不是只给一个相似度分数
- **出处** —— 每条事实都点得开产生它的那条归档记录，逐字原文
- **来源与信任级** —— 「你亲口说的」与「模型推断的」在界面上不是同一个颜色
- **时间回放** —— 拖那根滑块回到过去的任意一刻，看当时**已知**的记忆；
  当时成立、此后已被推翻的那些照样列出来并标红，因为那正是当时的真实认知

这个应用不含对话、工具确认、沙箱、项目、导入 —— 凡是需要 agent 才有意义的
一律不在这里。

## 跑起来

```bash
flutter pub get
flutter run -d chrome        # 或 -d windows
flutter build web --release
```

后端地址与凭据在**连接页上填**，没有编译期常量：Cormex 是自托管的，
把地址烤进构建里等于让每个部署者都得自己编一份客户端。凭据同理 ——
理由见 `lib/auth/credential_store.dart` 的模块注释。

需要一台跑着的 cormexd。凭据用 `cormexd --generate-token` 生成，
或者用账号密码（若该部署接了账号体系）。
